# English Home — sitio web
Sitio estático listo para GitHub Pages.

## Archivos
- index.html
- style.css
- script.js
- assets/

## Funciones
- Switch Español / English
- Formulario de prospectos
- Envío del formulario a WhatsApp
- Botones directos de WhatsApp
- Diseño responsive
- Sección de horarios, modalidades y ubicación

## Publicación
Sube todo el contenido de esta carpeta a un repositorio de GitHub y activa GitHub Pages desde Settings > Pages.
